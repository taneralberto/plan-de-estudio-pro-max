El progreso vive en el almacenamiento local de este navegador y este origen. No se sincroniza ni se envía a ningún sitio, y puede desaparecer al limpiar los datos del navegador.

Abre la web con un servidor HTTP local

Abrir Especializacioes/AppSec/web/index.html con doble clic no funciona: el navegador bloquea la lectura de los archivos .md desde file://.

Desde la raíz del repositorio ejecuta:

python3 -m http.server 8000 --bind 127.0.0.1

Y abre http://127.0.0.1:8000/Especializacioes/AppSec/web/ en el navegador.

Mientras tanto, los documentos se pueden leer en Markdown: ITINERARIO.md, README.md, RECURSOS.md, PROMPTS.md.
