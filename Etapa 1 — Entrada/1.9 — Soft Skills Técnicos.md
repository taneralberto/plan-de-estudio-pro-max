# 1.9 — Soft Skills Técnicos

> **Estado histórico:** integrado; no es una unidad que debas completar por separado.

Las habilidades siguen en la ruta, pero se practican donde producen evidencia:

- explicar decisiones a audiencias técnicas y no técnicas → [1.7 — Requirements, ADR y Explicación Técnica](1.7%20—%20Documentación%20Técnica%20Profesional.md);
- enseñar para comprobar comprensión → [METODOLOGIA.md](../METODOLOGIA.md#explicación-y-feedback);
- feedback y mentoría mediante un cambio concreto → [4.7 — Leer Código Ajeno y Code Review](../Etapa%204%20—%20Profundización/4.7%20—%20Leer%20Código%20Ajeno%20y%20Code%20Review.md);
- postmortems y aprendizaje de incidentes → [4.5 — Observabilidad y SRE](../Etapa%204%20—%20Profundización/4.5%20—%20Observabilidad%20(Los%203%20Pilares).md).

Liderazgo y mentoría profunda quedan JIT para una responsabilidad real de equipo. No se demuestra liderazgo grabando contenido adicional: se demuestra ayudando a otra persona a decidir o aprender sin hacerle el trabajo.
