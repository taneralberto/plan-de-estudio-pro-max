# 2.1 — TypeScript Avanzado

> **Estado: JIT** · Referencia de lenguaje no bloqueante.

## Cuándo abrir

Ante un error real del compilador, un tipo que no se estrecha como esperas o una decisión de configuración que necesites justificar.

## Conceptos mínimos

- **Narrowing:** usa controles de flujo (`typeof`, `in`, guards) para reducir una unión sin recurrir a casts.
- **Discriminated unions:** modela estados con un discriminante común en lugar de combinaciones inválidas de campos opcionales.
- **Exhaustividad:** comprueba con `never` que cada variante quede atendida cuando el dominio sea cerrado.
- **`tsconfig`:** audita `strict`, `target`/`lib` y `module`/`moduleResolution` según el runtime, las dependencias y la herramienta de build reales.

## Evidencia opcional

Un error reducido en TypeScript Playground o un cambio pequeño de tipos/configuración acompañado por la explicación del diagnóstico.
