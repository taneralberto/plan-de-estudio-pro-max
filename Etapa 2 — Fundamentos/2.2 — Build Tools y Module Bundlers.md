# 2.2 — Build Tools y Module Bundlers

> **Estado: JIT** · Referencia Web no bloqueante.

## Cuándo abrir

Cuando el build falle, tarde demasiado, genere un artefacto inesperado o entregue más JavaScript del necesario.

## Conceptos mínimos

- **Grafo ESM:** los imports/exports estáticos permiten resolver dependencias y optimizar el output.
- **Transpilación vs bundle:** transformar sintaxis no equivale a agrupar módulos; identifica qué etapa y herramienta produce cada artefacto.
- **Tree shaking y code splitting:** dependen del grafo, los efectos laterales y los puntos de carga dinámica; comprueba el resultado en vez de asumirlos.
- **Diagnóstico:** inspecciona logs, sourcemaps, chunks y el analyzer disponible en el build actual antes de migrar de herramienta.

## Evidencia opcional

Una captura o nota breve del output/analyzer que identifique la causa de un chunk grande, duplicado o ausente y el cambio medido.
