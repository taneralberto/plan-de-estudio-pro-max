# 2.5 — Almacenamiento Especializado

Destinos del contenido relacionado:

- colas, retries e idempotencia → [3.9 — Messaging y Event Streaming](../Etapa%203%20—%20Arquitectura/3.9%20—%20Messaging%20y%20Event%20Streaming.md), unidad 14;
- CAP, particiones y replicación → [3.10 — Sistemas Distribuidos](../Etapa%203%20—%20Arquitectura/3.10%20—%20Sistemas%20Distribuidos.md), unidad 14;
- MongoDB, Elasticsearch, Redis avanzado, wide-column, graph y time-series → JIT, solo ante un workload y requisito medidos.
