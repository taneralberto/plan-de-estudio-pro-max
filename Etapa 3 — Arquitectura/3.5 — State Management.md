# 3.5 — State Management

> **Estado: JIT** · Referencia Web no bloqueante.

## Cuándo abrir

Cuando una feature tenga estado duplicado, propietarios ambiguos, sincronización manual o una herramienta cuyo coste ya supere al problema.

## Conceptos mínimos

- **Clasificación:** separa estado local, compartido, del servidor y de URL; no todos necesitan un store global.
- **Owner y source of truth:** define quién puede cambiar cada dato y dónde vive su versión autoritativa.
- **Sincronización:** para estado remoto explicita carga, error, caché, invalidación y concurrencia sin duplicar innecesariamente la fuente del servidor.
- **Herramienta mínima:** empieza con las primitivas del framework actual y añade una librería solo ante una necesidad concreta y observable.
