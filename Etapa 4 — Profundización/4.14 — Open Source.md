# 4.14 — Open Source

> **Estado: JIT** · Referencia de carrera no bloqueante.

## Cuándo abrir

Cuando quieras preparar una contribución externa acotada o convertir código reusable en un paquete que otra persona pueda evaluar.

## Conceptos mínimos

- **Elige una vía:** prepara una PR **o** un paquete publicable; no necesitas hacer ambas cosas.
- **Scope:** define un cambio pequeño, motivación, límites y compatibilidad esperada.
- **Calidad verificable:** incluye tests relevantes, documentación de uso y CI reproducible.
- **Entrega autónoma:** deja la PR lista según la guía del proyecto o el paquete listo para publicar, sin depender de decisiones de terceros.

## Evidencia opcional

Una PR preparada, aunque no sea aceptada o mergeada, **o** un artefacto de paquete instalable localmente, aunque no se publique en un registry.
