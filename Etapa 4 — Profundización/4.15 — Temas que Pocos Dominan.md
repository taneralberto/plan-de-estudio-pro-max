# 4.15 — i18n, Regex y WASM — Alias/router JIT

> **Estado: ALIAS/ROUTER · JIT** · Este ID histórico no añade una unidad ni una actividad propia.

## Cuándo abrir

Usa solo la ruta que corresponda a un problema real:

- **i18n:** ante múltiples locales, pluralización, formatos o zonas horarias, vuelve a [`3.4 — Cómo funciona el Browser`](<../Etapa 3 — Arquitectura/3.4 — Cómo funciona el Browser.md>) y consulta la API nativa `Intl` antes de sumar una librería.
- **Regex y ReDoS:** ante validación o extracción acotada, vuelve a [`1.4 — Seguridad Aplicada`](<../Etapa 1 — Entrada/1.4 — Seguridad Aplicada.md>), limita longitud/tiempo y prueba inputs adversariales; para estructuras anidadas o lenguajes, usa un parser.
- **WASM:** ante un workload CPU-intensivo medido, vuelve a [`2.3 — Performance Engineering`](<../Etapa 2 — Fundamentos/2.3 — Performance Engineering.md>) para confirmar el cuello y a [`3.4 — Cómo funciona el Browser`](<../Etapa 3 — Arquitectura/3.4 — Cómo funciona el Browser.md>) para aislarlo en un Web Worker cuando corresponda.

## Evidencia opcional

La medición o caso mínimo que activó una de estas rutas y la decisión resultante; este router no exige evidencia propia.
