# 4.4 — Testing Backend y API

> **Estado histórico:** integrado; no es una unidad que debas completar por separado.

El dueño único de testing y oracles es [1.3 — Testing y Oracles Externos](../Etapa%201%20—%20Entrada/1.3%20—%20Testing%20Fundamentals.md). Allí se integran:

- comportamiento, riesgo, doubles y coverage;
- tests de función, PostgreSQL real con Testcontainers y contrato HTTP;
- property-based testing/fuzzing básico;
- un caso adversarial para una implementación plausible o generada por AI.

Los temas especializados quedan donde aparece su necesidad:

- contract testing entre servicios → JIT cuando exista un consumidor independiente;
- E2E de frontend → [3.7 — Testing Frontend](../Etapa%203%20—%20Arquitectura/3.7%20—%20Testing%20Frontend.md), ruta Web JIT;
- automatización de la suite → [4.2 — CI/CD](4.2%20—%20CI-CD%20(Integración%20y%20Entrega%20Continua).md);
- auditoría completa de un cambio generado → unidad 19 del [ROADMAP](../ROADMAP.md).

No agregues otra suite ni otro Done por abrir este archivo.
