# Plan de Estudio Pro Max

Un plan de aprendizaje para convertirte en un ingeniero de software completo en la era de AI. 4 etapas, ~46 temas, cada uno con criterio de dominio claro.

## Filosofía

1. **Conceptos antes que código** — No se toca un framework sin entender qué problema resuelve. Un framework es una herramienta; si no entiendes el problema, no puedes evaluar si es la correcta.

2. **Cada etapa construye sobre la anterior** — Saltar etapas es como construir el segundo piso sin cimientos.

3. **Si no puedes explicarlo, no lo dominas** — No marques un tema como completado hasta que puedas explicarlo a otro programador sin mirar apuntes.

4. **La AI implementa, tú decides** — La AI puede escribir código, pero no puede decidir cuándo ni cómo para tu contexto. Tu trabajo es saber qué pedirle, cómo verificarlo y qué decidir. Cada línea de código generado por AI que aceptas, la aprobaste tú.
